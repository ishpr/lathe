# Licence allowlist (REC-23). One file, under CODEOWNERS. Tiers are agreed with the client's
# legal owner, whose name goes in the next line before this file is relied on.
# Legal owner: to be named
#
# Format: tier|licence name exactly as pip-licenses prints it, one per line. Lines starting
# with # are comments. Names are matched exactly (pip-licenses compares whole strings). Recent
# packages report SPDX ids (MIT, BSD-3-Clause, Apache-2.0); older ones report classifier names
# (MIT License, BSD License), so both spellings are listed. Confirm each name against
# `pip-licenses --format=csv` on the locked environment and add the spelling a new package uses.
#
# Tier 1: allowed with no review.
# Tier 2: allowed with a note in the PR (weak copyleft; keep the library separate, unmodified).
# Tier 3: not allowed. A package with an UNKNOWN licence is a failure until a human classifies it.
#
# The CI step builds its arguments from this file, after the locked install:
#   --allow-only  = the names on tier 1 and 2 lines:  grep -E '^[12][|]' | cut -d'|' -f2
#   --fail-on     = the names on tier 3 lines:        grep -E '^3[|]'    | cut -d'|' -f2
#   --ignore-packages = the package on each exception| line
# --allow-only fails a package only when none of its licences is listed; --fail-on fails on any
# listed tier-3 name even when a second licence is allowed. Both exit 1. Run the step's commands
# by hand to check a change to this file before you push it.
